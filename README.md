# Wine Classification using Machine Learning

## Project Overview
This project focuses on classifying wine types using machine learning algorithms. It compares multiple models and evaluates their performance.

## Techniques Used
- Random Forest Classifier
- AdaBoost Classifier
- Gradient Boosting Classifier

## Results
- Random Forest Accuracy: 97.8%
- AdaBoost Accuracy: 97.2%
- Gradient Boosting Accuracy: 94.4%

## Key Features
- Feature Importance Analysis
- Model Comparison
- Data Splitting (Train/Test)
- Visualization of Decision Tree

## Tools & Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Conclusion
Random Forest performed best for this dataset with high accuracy and interpretability.
